# 📤 outputs — 最终产出

> **原则：可对外交付的成品。** 基于 wiki 知识生成的实际产出物。

## 放什么

- **学习笔记**：整理好的专题笔记，适合复习
- **项目报告**：仿真项目的分析报告、结论
- **博客文章**：准备发布的公开文章
- **面试准备**：高频考题、概念速答
- **演讲 / PPT 提纲**：技术分享的讲稿

## 工作流

1. wiki 里某个领域的知识攒够了
2. 告诉 LLM："基于 `wiki/电磁仿真/` 下的内容，帮我生成一份学习笔记"
3. 产出放入 `outputs/` 对应子目录

## 和 wiki 的区别

| | wiki | outputs |
|:---|:---|:---|
| 性质 | 知识库，持续更新 | 产品，完成即冻结 |
| 受众 | 你自己 | 你自己或他人 |
| 格式 | 原子化、互联 | 线性、独立可读 |
| 更新 | 随时打磨 | 一般不更新，出新版本 |

> 💡 可以把 outputs 想象成"wiki 的编译产物"——wiki 是源码，outputs 是构建好的二进制。
