# 正向与逆向代理模型训练 — 摘要

> **原始资料**: [[raw/模型训练/2026-06-09_正向与逆向模型训练记录.md]]
> **原始数据**: `Backfeed_Data300.xlsx` (300 行 × 1001 点 S11, 2.0-2.6 GHz)
> **模型文件**: `model_forward_full_pca.pth` / `model_inverse_tandem.pth`

## 📌 核心内容

本次实验用 PyTorch 构建了电磁结构 S11 曲线的**正向代理模型**和**逆向设计模型**，基于 300 个 CST/HFSS 仿真样本，将师兄的旧代码从 51 点改造为完整 1001 频点。

**数据集**：
- 输入变量：`sx` (0-12)、`sy` (0-9)、`sl` (1-5)、`sw` (2-10)
- 固定参数：`L=39.6`、`W=39.6`、`Q=4`（当前数据中不变）
- 输出：1001 点 S11 dB 曲线，频率范围 2.0-2.6 GHz，步长 0.6 MHz

## 🔑 关键结果

### 正向模型（4 参数 → S11 曲线）

| 指标 | 训练集 | 验证集 |
|:---|---:|---:|
| 曲线 MAE | 0.217 dB | **0.394 dB** |
| 曲线 RMSE | 0.528 dB | 1.244 dB |
| 谐振频率 MAE | 1.05 MHz | **4.28 MHz** |
| 谷底深度 MAE | 1.52 dB | 4.36 dB |
| 中位 MAE | — | 0.333 dB |
| 90% 分位 MAE | — | 0.710 dB |
| 最差 MAE | — | 1.905 dB |

**技术方案**：MLP (3×128, SiLU) → PCA 50 维（解释率 99.986%）→ 加权损失（深谐振区加权 ×20）→ 早停 (patience=500)。不转线性幅值，直接在 dB 域训练。

### 逆向模型（S11 曲线 → 4 参数 + 正向回代）

| 指标 | 验证集 |
|:---|:---|
| sx MAE | 2.569 |
| sy MAE | 2.208 |
| sl MAE | **0.984** |
| sw MAE | **1.040** |
| 回代曲线 MAE | **0.448 dB** |
| 回代中位 MAE | 0.256 dB |
| 谐振频率误差 | 5.18 MHz |
| 谷底深度误差 | 4.33 dB |

**技术方案**：Tandem 架构——逆向网络预测尺寸 → 冻结的正向模型回代曲线 → 双重损失（尺寸 MSE + 曲线加权损失）。输入特征：PCA 50 维 + 谐振频率 + 谷底深度 + -10dB 带宽 + 曲线积分。

### 多候选搜索（核心亮点）

逆向映射不唯一（不同尺寸 → 相似 S11）。对第一条数据做多起点优化搜索，找到 5 组候选：

| 排名 | sx | sy | sl | sw | 曲线 MAE | 频率误差 |
|:---|---:|---:|---:|---:|---:|:---|
| 1 | 9.66 | 7.96 | 1.37 | 9.38 | **0.218 dB** | 0.0 MHz |
| 2 | 4.09 | 7.24 | 4.59 | 5.83 | 0.290 dB | 0.6 MHz |
| 3 | 7.35 | 4.24 | 2.75 | 7.44 | 0.307 dB | 0.0 MHz |

> 第 1 候选的回代曲线效果极好（MAE 0.218 dB），尺寸与真实值 `(10, 8.5, 1.4, 9.5)` 接近但不完全相同——体现了多解性。
