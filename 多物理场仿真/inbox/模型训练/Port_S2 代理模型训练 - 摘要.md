# Port_S2 代理模型训练 — 摘要

> **原始记录**: [[raw/模型训练/6_10文件/2026-06-10_正向与逆向模型训练记录_Port_S2.md]]
> **数据**: `Port_S_data_2_1-8GHz.xlsx` — 72 样本，40 频点 (1-8 GHz)，参数 l3 × w4

## 💭 今天干了什么

在 WavEDA 里建了一个微带贴片天线模型，对 l3（9-17）和 w4（0.5-4.0）两个尺寸参数做扫参，生成了 72 组 S11 曲线。然后把这批数据喂给神经网络做正向代理和逆向设计，顺带搭了一套自动化的多候选搜索流程。

整个流程：**WavEDA 仿真 → Touchstone 导出 → Excel 格式转换 → ML 训练 → 逆向候选搜索**。

## 👀 WavEDA 建模

在 WavEDA Layout 里建了微带贴片天线结构，然后在 EM 模块里做了双参数扫参。出来的 Touchstone 文件转成了 `Backfeed_Data300` 同款的 Excel 格式，这样才能复用之前的训练 pipeline。

## 🧠 正向模型（l3, w4 → S11 曲线）

和上次 Backfeed_Data300 同样的架构：PCA 25 维（解释率 99.92%）+ MLP 3×128 SiLU + 加权损失。

| 指标 | 5-Fold CV | 全数据训练 |
|:---|---:|:---|
| 曲线 MAE | 0.99 ± 0.12 dB | **0.72 dB** |
| 谐振频率误差 | 680 ± 167 MHz | — |

72 样本量下表现还过得去。7 GHz 带宽里 680 MHz 的频率误差约 10%，基本可用。

## 🔄 逆向模型（S11 → l3, w4）

Tandem 架构，32 维特征（25 PCA + 7 维物理特征：谐振频率、深度、带宽、积分等）。

| 指标 | 5-Fold CV | 全数据训练 |
|:---|---:|:---|
| 参数 MAE | 0.40 ± 0.10 | — |
| **l3 MAE** | — | **0.13** |
| **w4 MAE** | — | **0.03** |

**有趣的现象**：w4 的辨识精度远高于 l3（0.03 vs 0.13）。w4 对 S11 形状的影响更显著，网络更容易"抓住"它。

回代曲线 MAE：0.83 dB（全数据），CV 1.09 dB。

## 🔬 优化尝试（6 种方案）

试了一圈改进，结论很明确：**72 样本太少，数据量是根本瓶颈。**

| 改进 | 效果 |
|:---|:---|
| 共振感知 Loss（显式惩罚频率/深度） | ✅ 频率误差降 21%（680→538 MHz） |
| 余弦退火 LR | 持平 |
| 更宽网络 + 残差连接 | ❌ 过拟合 |
| 数据增强（输入噪声） | ❌ 物理不一致 |
| 动态 Tandem 权重 | ❌ 小数据下不稳定 |
| Dropout 正则化 | 轻微改善 |

目前的 best model 还是 baseline。唯一有效的改进是共振感知 Loss。

## 🤔 和上次 Backfeed_Data300 的对比

| | Backfeed_Data300 | Port_S2 |
|:---|:---|:---|
| 样本数 | 300 | **72** |
| 参数维度 | 4 | 2 |
| 频段 | 2.0-2.6 GHz | **1.0-8.0 GHz** |
| 正向 MAE | 0.39 dB | 0.72 dB |
| 逆向回代 MAE | 0.45 dB | 0.83 dB |

样本少了一个数量级，误差翻了一倍——但考虑到只有 72 个样本，0.72 dB 其实还行。2 参数比 4 参数容易建模，但频带宽了 10 倍，对模型的要求也更高。
