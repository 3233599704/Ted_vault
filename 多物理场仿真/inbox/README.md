# 📋 inbox — 处理中

> **原则：LLM 的第一次输出。** 未经人工精炼的半成品，等待你审阅和升级。

## 放什么

- LLM 对 raw 资料的**摘要**、**翻译**、**要点提取**
- LLM 第一次回答的"小白问题"（以后可以精炼成 wiki）
- 对软件教程的**步骤拆解**
- 从论文提取的**关键公式和结论**

## 命名规范

```
{原始资料名} - 摘要.md
{问题简述} - Q&A.md
```

示例：
- `Maxwell方程综述 - 摘要.md`
- `COMSOL网格剖分怎么选 - Q&A.md`

## 质量要求（低）

- 可以粗糙，可以有冗余——这是"待处理"状态
- 但必须**准确**——错误的信息比没有信息更糟糕
- 记得标上来源 → `[[raw/电磁仿真/某文件.md]]`

## 工作流

1. 从 raw → LLM 处理 → 产出放入 inbox
2. 定期 review inbox 中的内容
3. 质量高的 → 精炼后移入 `wiki/`
4. 质量不足的 → 标注问题，重新让 LLM 处理
5. inbox 应该保持"可管理的大小"——不要堆积
