# 飞书 Bot 构建复盘 — 摘要

> **原始记录**: [[raw/飞书-Claude-Obsidian-Bot-构建复盘与复现日志.md]]
> **Bot 状态**: 已投入使用，支持连续会话、图片识别、语音回复、开机自启、断线自愈

## 💭 项目概述

三天时间把飞书 Bot 从跑通基础链路做到了"日常可用"的成熟度。手机飞书发消息 → WebSocket 长连接 → Claude Code CLI → 读写 Obsidian Vault。

**最终不是"偶尔能跑"，是日常稳定运行的本地 AI 入口。**

## 🗓️ 构建时间线

| 日期 | 做了什么 |
|:---|:---|
| **06-12** | 基础链路跑通：飞书长连接 → Claude Code CLI → 文字回复。硬编码改环境变量，加计划任务自启，加连续会话，加图片识别（MiMo Vision） |
| **06-13** | 语音系统：MiMo TTS + Voice Clone + 动态演绎风格（8种预设）+ 语音/文字模式切换 + Markdown转纯文本 |
| **06-14** | 稳定性：电脑睡眠后连接假死修复、健康心跳监控、240秒自动重启、文件锁防重复启动、每日蒸馏通知 |

## 🔑 核心亮点

**语音系统**：Vera 有自己的声音了。Voice Clone 固定音色 + "语音导演"动态选演绎风格（natural / romantic / technical / comforting 等 8 种）。专门调了 romantic 预设——不能太慢太刻意，要自然偏快、放松咬字。加了 1.10x 不变调加速。

**面向失败设计**：每一层都有降级路径——session 失效 → 新会话重试；TTS 失败 → 回退文字；429 限流 → 退避重试；WebSocket 假死 → 自动重启。

**飞书适配**：Markdown 转纯文本、WAV 转 Opus、消息长度控制——不是"能调用"了事，而是做到"能用"。

## 🔧 解决了 13 个问题

从 Claude 超时到电脑睡眠后消息丢失，从 MiMo 429 到语音导演 JSON 解析失败，每个都记了根因和修复方案。最长的一篇复盘文档（760 行）。
