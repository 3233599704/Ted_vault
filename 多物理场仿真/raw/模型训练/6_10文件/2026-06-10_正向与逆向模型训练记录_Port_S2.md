# 正向与逆向模型训练记录 — Port_S2 1-8GHz

## 今日目标

1. 将 CST 导出的 Touchstone 格式 S 参数文件转换为标准 Excel 训练格式。
2. 为 Port_S2 天线结构（参数 l3、w4）训练正向模型和逆向模型。
3. 5 折交叉验证评估泛化能力。
4. 构建基于批量梯度下降的逆向多候选搜索。
5. 尝试多种优化策略提升模型效果。

## 数据来源与格式转换

### 原始文件

- `Port_S_data_1.txt`：S(1,1), w2=9~12, 41 频点 (1.3-1.5 GHz)，单参数扫参。
- `Port_S_data_2.txt`：S(1,1), l3=9~17 × w4=0.5~4.0, 40 频点 (1.0-3.0 GHz)，双参数扫参。
- **`Port_S_data_2参数_1-8ghz.txt`（今日主要数据）**：同上参数范围，**40 频点 (1.0-8.0 GHz)**，频带更宽。

所有文件格式：Touchstone-like，前 4 行为 `%` 注释头，后续行以空格分隔 `频率 S11_1 S11_2 ...`。

### 转换规则

沿用 `Backfeed_Data300.xlsx` 的列结构：

```
[结构参数...] | [Unnamed: 15 空列] | [S11@f1] [S11@f2] ... [S11@fN]
```

最终数据：

- 文件：`Port_S_data_2_1-8GHz.xlsx`
- 72 行 × 43 列（l3 + w4 + 空列 + 40 频点）
- l3：9, 10, 11, 12, 13, 14, 15, 16, 17（9 个值）
- w4：0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0（8 个值）

## 正向模型 `(l3, w4) → S11`

### 方案

- PCA 压缩 40 点曲线 → 25 维系数（解释率 99.92%）
- MLP: 2→128→128→128→25，SiLU 激活
- 加权 MSE Loss（深谐振区域权重更高）
- 5 折交叉验证
- 早停 patience=500

### 结果

| 指标 | 5-Fold CV | Final（全数据） |
|---|---|---|
| **Curve MAE** | **0.99 ± 0.12 dB** | **0.72 dB** |
| RMSE | 1.88 ± 0.20 dB | — |
| **谐振频率误差** | 680 ± 167 MHz | — |
| 谷底深度误差 | 3.43 ± 0.87 dB | — |

**结论：** 72 样本条件下泛化尚可。大多数曲线趋势和谐振位置拟合到位，少数困难样本出现偏差。7 GHz 带宽下 680 MHz 频率误差约 10%，可接受。

## 逆向模型 `S11 → (l3, w4)`

### 方案（Tandem）

- 输入特征：25 PCA 系数 + 7 维手工特征（谐振频率、深度、-10dB/-3dB 带宽、积分面积、均值、标准差）
- 网络：32→256→256→128→2 + Sigmoid，Dropout(0.1)
- 损失 = 参数 MSE + 0.5×正向回代曲线 Loss
- 正向模型冻结，仅训练逆向网络

### 结果

| 指标 | 5-Fold CV | Final（全数据） |
|---|---|---|
| **Param MAE** | **0.40 ± 0.10** | — |
| **l3 MAE** | — | **0.13** |
| **w4 MAE** | — | **0.03** |
| **回代曲线 MAE** | 1.09 ± 0.19 dB | **0.83 dB** |

**关键发现：** w4 的辨识精度远高于 l3（0.03 vs 0.13），w4 对 S11 形状的影响更显著。

## 优化尝试

### 尝试的改进

| 改进 | 效果 |
|---|---|
| 共振感知 Loss（显式惩罚频率/深度误差） | ✅ CV 频率误差 **-21%**（680→538 MHz） |
| 余弦退火 LR | 持平 |
| 更宽网络 (256) + 残差连接 | ❌ 过拟合（72 样本太少） |
| 数据增强（输入噪声） | ❌ 物理不一致，反效果 |
| 动态 Tandem 权重 | ❌ 小数据下不稳定 |
| Dropout 正则化 | 轻微改善 |

### 最终结论

72 样本是根本瓶颈。唯一有效改进是共振感知 Loss，频率精度提升 21%。**当前最佳模型仍为 baseline**。

## 逆向多候选搜索

### 方法

多起点批量梯度下降，基于冻结正向模型：

1. 在 (l3, w4) 有效范围内随机生成 100 个起点。
2. 批量并行优化 300 步（Adam, lr=0.1），损失 = 加权 MSE + 谐振惩罚 + 边界惩罚。
3. 按曲线 MAE 排序，去重（欧氏距离 < 0.3），取 Top-10。

### 搜索结果

| 指标 | 值 |
|---|---|
| **Top-1 曲线 MAE（中位）** | **0.71 dB** |
| **MAE < 1.0 dB** | **82%** |
| **频率误差（中位）** | **0.0 MHz** |
| **真实尺寸在 Top-3** | **79%** |
| **真实尺寸在 Top-10** | **89%** |
| 逆向 vs 正向着中位 MAE 差距 | +0.07 dB |

**结论：** 批量梯度下降搜索几乎达到正向模型的精度上限。82% 样本重建 MAE < 1 dB。Top-10 候选覆盖 89% 的真实尺寸。对于仅 72 个训练样本，表现可靠。

## 后续改进方向

**优先级 1：增加训练数据**

当前 72 样本是最大瓶颈。加密 l3×w4 网格到 13×12=156 或更多，模型效果可跳一个台阶。

**优先级 2：加密频率采样**

40 个频点对 1-8 GHz 略粗（步进 ~180 MHz），增到 100+ 能更好解析谐振谷细节。

**优先级 3：物理约束**

将谐振频率、带宽等作为辅助输出，让网络学习物理规律而非纯拟合。

**优先级 4：真实仿真验证**

将逆向候选尺寸导入 CST/HFSS 仿真，对比代理模型与真实曲线，建立"逆向生成→仿真→数据回流"闭环。
