2. 核对 Excel 数据结构，使用完整 S11 曲线训练，而不是旧代码中的 51 个点。

## 数据核对

- 数据文件：`Backfeed_Data300.xlsx`
- 样本数量：300 行。
- 总列数：1017 列。
- 第 1-15 列：结构参数及辅助参数。
- 第 16 列：空白分隔列 `Unnamed: 15`。
- 第 17 列至最后一列：完整 S11，共 1001 个频点。
- 频率范围：`2.0-2.6 GHz`。
- 频率间隔约：`0.0006 GHz = 0.6 MHz`。

当前数据中保持不变的参数：

- `L = 39.6`
- `W = 39.6`
- `Q = 4`
- 其他辅助结构参数同样基本固定。

实际变化并用于模型训练的尺寸：

- `sx`：0-12
- `sy`：0-9
- `sl`：1-5
- `sw`：2-10

## 发现的原始代码问题

## 正向模型

### 任务定义

输入：

`sx, sy, sl, sw`

输出：

完整 1001 点 S11 曲线。

### 最终方案

- 直接在 dB 域学习，不再转为线性幅值。
- 输入尺寸使用训练集统计量标准化。
- 使用 PCA 压缩完整曲线。
- 完整曲线需要约 34 个 PCA 分量达到 99.9% 信息保留。
- 最终模型采用 50 个 PCA 分量，解释率约 99.986%。
- 网络预测 PCA 系数，再重建 1001 点曲线。
- 损失函数对深谐振区域增加权重。
- 使用早停，避免继续拟合训练集导致验证误差上升。

### 正向模型结果

验证集：

- 完整曲线平均 MAE：`0.394 dB`
- 完整曲线 RMSE：`1.244 dB`
- 谐振频率平均误差：`4.28 MHz`
- 谷底深度平均误差：`4.36 dB`

第一条训练数据：

- 真实谷底：`-40.394 dB @ 2.3894 GHz`
- 预测谷底：约 `-39.239 dB @ 2.3894 GHz`

全部验证样本分布：

- 中位曲线 MAE：`0.333 dB`
- 90% 分位 MAE：`0.710 dB`
- 最差样本 MAE：`1.905 dB`

结论：大多数曲线趋势和谐振位置拟合较好，但少数异常样本会出现错误振荡或谷底深度偏差。

## 逆向模型

### 任务定义

输入：

完整 1001 点目标 S11 曲线。

输出：

`sx, sy, sl, sw`

固定参数 `L, W, Q` 自动补回。

### 逆向问题的特殊性

逆向映射不是严格的一一对应关系。不同尺寸组合可能产生非常接近的 S11 曲线，因此：

- 预测尺寸与原始尺寸不同，不一定代表设计无效。
- 更重要的评价方式是：将预测尺寸送回正向模型后，能否重建目标曲线。
- 正向代理模型仍有误差，候选尺寸最终必须放入 CST/HFSS 重新仿真确认。

### 最终 Tandem 方案

逆向输入特征：

- 完整曲线的 50 个 PCA 系数。
- 谐振频率。
- 谷底深度。
- `-10 dB` 带宽。
- 曲线积分面积。

逆向输出：

- 标准化到 0-1 范围的 `sx, sy, sl, sw`。
- 输出使用 Sigmoid，保证尺寸不超过数据范围。

训练损失：

1. 预测尺寸与真实尺寸的误差。
2. 预测尺寸经过冻结正向模型后的回代曲线误差。
3. 对深谐振区域增加权重。

### 逆向模型结果

验证集尺寸 MAE：

| 参数 | MAE |
|---|---:|
| sx | 2.569 |
| sy | 2.208 |
| sl | 0.984 |
| sw | 1.040 |

验证集正向回代曲线：

- 平均 MAE：`0.448 dB`
- 中位 MAE：`0.256 dB`
- RMSE：`1.077 dB`
- 谐振频率平均误差：`5.18 MHz`
- 谷底深度平均误差：`4.33 dB`

结论：

- `sw` 相对更容易辨识。
- `sx、sy` 的恢复误差较大。
- 曲线回代效果通常好于尺寸还原效果。
- 验证集超过一半样本回代效果较好，但困难样本仍可能错过谷底。

## 逆向多候选搜索

### 方法

当前逆向网络每次只输出一组尺寸，无法直接表示多解。因此新增基于正向模型的多起点连续优化：

1. 在允许尺寸范围内随机生成大量起点。
2. 使用正向模型计算每组尺寸对应的 1001 点曲线。
3. 优化尺寸，使曲线接近目标。
4. 按曲线 MAE、谐振频率误差和谷底深度误差筛选。
5. 去除尺寸过于接近的重复候选。

“所有解”在连续空间中理论上可能无限，因此实际输出的是彼此差异明显的高质量候选集合。

## 当前判断

### 正向模型

- 已具备较好的快速估计能力。
- 谐振位置通常较准。
- 谷底深度和困难样本仍需改进。

### 逆向模型

- 可生成能近似复现目标曲线的尺寸。
- 不适合将单输出尺寸直接解释为唯一真实尺寸。
- 多候选搜索比单输出网络更符合逆向设计问题。
- 所有候选必须经过真实电磁仿真验证。

## 后续改进方向

优先级 1：改进正向模型

- 增加训练数据，特别是当前最差样本附近的参数区域。
- 对困难样本进行主动学习或局部加密采样。
- 增加谐振频率、谷底深度和带宽的显式损失。
- 尝试平滑基函数、AutoEncoder 或 1D CNN 表示完整曲线。
- 对正向模型做交叉验证或模型集成，估计预测不确定性。

优先级 2：改进逆向多解能力

- 使用 MDN、Conditional VAE、Normalizing Flow 等概率生成模型。
- 输出候选分布，而不是单一尺寸。
- 在候选搜索中加入制造约束、尺寸步长和设计偏好。
- 对每组候选输出置信度和正向模型不确定性。

优先级 3：提高物理可信度

- 将候选尺寸批量导入 CST/HFSS。
- 对比真实仿真曲线和代理模型曲线。
- 将仿真误差较大的候选加入训练集继续训练。
- 建立“逆向生成 → 电磁仿真 → 数据回流”的闭环。

## 最终结论

本次工作已将旧的 51 点示例代码改造成使用完整 1001 点 S11 的正向和逆向训练流程。

正向模型可较好预测多数样本的曲线和谐振位置；逆向模型能够生成回代曲线接近目标的尺寸，但尺寸存在明显多解性。当前最合理的使用方式不是只取逆向网络的一组输出，而是生成多组候选，再使用 CST/HFSS 做最终确认。
