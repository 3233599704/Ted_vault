# 📥 raw — 原始资料

> **原则：永不修改。** 这里是知识的"原材料仓库"。

## 放什么

- PDF 论文、教材章节、技术手册
- 网页全文抓取（用剪藏工具保存的 Markdown / HTML）
- 课堂笔记照片、手写扫描件
- 视频字幕 / 转录文本
- 原始数据、仿真输入文件说明

## 不放什么

- 自己的总结 → 去 `inbox/` 或 `wiki/`
- 翻译 → 去 `inbox/`
- 加工后的笔记 → 去 `outputs/`

## 命名规范

```
{来源类型}_{年份}_{简短描述}.md
```

示例：
- `论文_2023_高效电磁仿真综述.md`
- `网页_2024_COMSOL热分析教程.md`
- `笔记_2025_天线理论课堂笔记.md`

## 工作流

1. 新资料先扔进对应领域的子目录
2. 积攒一定量后，批量让 LLM 读取并生成 inbox 摘要
3. raw 里的文件**永远不删不改**——它是你的"原始档案"
