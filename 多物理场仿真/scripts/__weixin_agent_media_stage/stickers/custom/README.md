# Vera 自定义表情库

把静态 PNG、JPG 或 WebP 图片直接放进这个文件夹，Bot 会自动发现，不需要重启。

文件名就是使用场景标签，使用下划线分隔，例如：

- `开心_夸奖_得意.png`
- `委屈_撒娇_想你.webp`
- `无语_嫌弃_白眼.jpg`
- `安慰_抱抱_心疼.png`

Vera 会在正常回复时自行判断是否使用，并从文件名标签中选择。不是每条消息都会发图。

发送前，会先移除与图片四周连通的近白色底色，再按原图长宽比添加一圈窄透明边。主体默认占最终图片的约 82%，不会再使用大面积正方形留白；缓存放在 `stickers/cache/`，原图不会被改动。

当前仅支持静态图片。文件名只写情绪和场景，不要放隐私信息。
