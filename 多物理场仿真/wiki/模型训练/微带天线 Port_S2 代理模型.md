# 微带天线 Port_S2 代理模型

> WavEDA 仿真 → Touchstone 导出 → ML 训练 → 逆向候选搜索。72 样本，2 参数 (l3, w4)，40 频点 (1-8 GHz)。

## 💭 做了什么

在 WavEDA 里建了微带贴片天线模型，对 l3（9-17）和 w4（0.5-4.0）做双参数扫参，72 组 S11 曲线。然后把这批数据喂给神经网络做正向代理和逆向设计。

**完整链路**：WavEDA 仿真 → Touchstone 导出 → Excel 格式转换 → ML 训练 → 逆向候选搜索。

## 👀 WavEDA 建模

在 WavEDA Layout 里建了微带贴片天线结构，EM 模块双参数扫参，Touchstone 文件转成 `Backfeed_Data300` 同款 Excel 格式。

![[a24050df31ee7a915e6c59a84ab9d9f4.png]]

## 🧠 正向模型（l3, w4 → S11）

PCA 25 维（解释率 99.92%）+ MLP 3×128 SiLU + 加权损失。

| 指标 | 5-Fold CV | 全数据 |
|:---|---:|:---|
| 曲线 MAE | 0.99 ± 0.12 dB | **0.72 dB** |
| 谐振频率误差 | 680 ± 167 MHz | — |

## 🔄 逆向模型（S11 → l3, w4）

Tandem 架构，32 维特征（25 PCA + 7 维物理特征：谐振频率、深度、带宽、积分）。

| 指标 | 5-Fold CV | 全数据 |
|:---|---:|:---|
| 参数 MAE | 0.40 ± 0.10 | — |
| l3 MAE | — | **0.13** |
| w4 MAE | — | **0.03** |
| 回代曲线 MAE | — | 0.83 dB |

w4 辨识精度远高于 l3（0.03 vs 0.13），w4 对 S11 影响更显著。

| Top-1 曲线 MAE（中位） | 0.71 dB |

## 🔬 优化尝试（6 种）

**72 样本是根本瓶颈。**

| 改进 | 效果 |
|:---|:---|
| 共振感知 Loss | ✅ 频率误差降 21%（680→538 MHz） |
| 余弦退火 LR | 持平 |
| 更宽网络 + 残差 | ❌ 过拟合 |
| 数据增强 | ❌ 物理不一致 |
| 动态 Tandem 权重 | ❌ 不稳定 |
| Dropout | 轻微改善 |

## 🤔 和 Backfeed_Data300 对比

| | Backfeed_Data300 | Port_S2 |
|:---|:---|:---|
| 样本数 | 300 | **72** |
| 参数维度 | 4 | 2 |
| 频段 | 2.0-2.6 GHz | **1.0-8.0 GHz** |
| 正向 MAE | 0.39 dB | 0.72 dB |
| 逆向回代 MAE | 0.45 dB | 0.83 dB |

样本少一个数量级，误差翻倍。但 72 样本下有 0.72 dB 算可以。
