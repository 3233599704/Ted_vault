# 代理模型与降阶模型

> 用一个便宜的"替身"来替代昂贵的数值仿真——这是 ML 在多物理场仿真中最核心的价值主张。

## 📖 是什么

**代理模型（Surrogate Model）** 和 **降阶模型（Reduced Order Model, ROM）** 是两种用低成本近似替代高成本仿真的方法：

| | 代理模型 | 降阶模型 |
|:---|:---|:---|
| 本质 | 黑箱拟合（Data-driven） | 投影降维（Physics-aware） |
| 输入 | 设计参数 → 输出量 | 完整场 → 低维表示 |
| 方法 | MLP / GPR / Random Forest | POD / SVD / 本征正交分解 |
| 优点 | 灵活、不需 PDE 知识 | 保留物理结构、可解释 |
| 缺点 | 需要大量数据 | 对非线性/参数变化敏感 |
| 典型代表 | 神经网络回归 | Proper Orthogonal Decomposition (POD) |

> 现代趋势：**两者融合**——用神经网络做 ROM（如 DL-ROM、AE-ROM）。

## 🧠 为什么重要

- 一次高保真仿真可能要跑几小时甚至几天
- 设计优化需要成千上万次仿真 → 不可能直接跑
- 代理模型训练只需少量仿真数据，推理毫秒级
- 在多物理场耦合中尤其关键——一个场算一次就要命，嵌套迭代更不可行

## 📐 核心公式

### 降阶模型（POD 方法）

将高维解场 $\mathbf{u} \in \mathbb{R}^N$ 投影到低维空间 $\mathbb{R}^r$（$r \ll N$）：

$$
\mathbf{u} \approx \mathbf{V}_r \mathbf{a}
$$

- $\mathbf{V}_r$ — POD 基（从快照 SVD 得到的前 $r$ 个模态）
- $\mathbf{a}$ — 低维系数
- $N$ — 原始自由度（百万量级），$r$ — 降阶维度（10~50）

### 代理模型（回归形式）

$$
y = f_\theta(\mathbf{x}), \quad \mathbf{x} \in \mathbb{R}^d,\ y \in \mathbb{R}
$$

- $\mathbf{x}$ — 设计参数（几何、材料、频率……）
- $y$ — 感兴趣的输出量（S 参数、温度、谐振频率……）
- $f_\theta$ — 神经网络或其他回归器

## 🔧 在仿真中怎么用

| 步骤 | 做什么 |
|:---|:---|
| 1. 采样 | 用 LHS/Sobol 在设计空间撒 N 个点 |
| 2. 仿真 | 跑 N 次高保真仿真（用 COMSOL/HFSS 等） |
| 3. 训练 | 用仿真数据训练代理模型 |
| 4. 验证 | 留一部分数据测试精度 |
| 5. 部署 | 用代理模型替代仿真做优化/UQ/实时预测 |

## ⚠️ 常见坑

- **数据太少**：高维参数空间 + 少量样本 = overfitting
- **外推失败**：代理模型在训练域外不可信，别让它做外推
- **物理不合理**：纯数据驱动可能违反守恒律——考虑 PINN
- **采样不均匀**：LHS 比随机采样好，自适应采样比 LHS 好
- **评估只看 MSE**：MSE 低不代表物理正确——检查残差/守恒量
