# FDM vs FEM vs FVM 有什么区别？

> 三个都用来把 PDE 变成代数方程，区别在于"怎么切"和"在哪切"。

## 📊 一句话对比

| | 有限差分法 FDM | 有限元法 FEM | 有限体积法 FVM |
|:---|:---|:---|:---|
| 网格 | 规则的矩形网格 | 任意形状的三角形/四面体 | 任意形状的多面体 |
| 求解变量 | 网格点上的值 | 节点上的值（基函数插值） | 控制体上的积分平均值 |
| 基于 | 微分形式 PDE | 积分（弱）形式 PDE | 守恒定律的积分形式 |
| 最大优点 | 简单直观 | 适应复杂几何 | 天然守恒 |
| 最大缺点 | 复杂几何 gg | 数学门槛高 | 高精度扩展困难 |
| 代表软件 | —（多为自写） | COMSOL, HFSS | ANSYS Fluent, OpenFOAM |

## 🧠 类比理解

- **FDM**：像俄罗斯方块——只能处理矩形形状，但实现简单
- **FEM**：像乐高积木——什么形状都能拼，但需要理解基函数和弱形式
- **FVM**：像会计记账——每个格子的流入流出必须平衡，天然保证守恒

## 🔧 怎么选

| 你的问题 | 推荐方法 |
|:---|:---|
| 规则几何 + 简单 PDE | FDM（自己写代码验证） |
| 复杂几何 + 电磁/结构 | FEM（COMSOL/HFSS） |
| 流体/传热 | FVM（Fluent/OpenFOAM） |
| 光子学/宽带 | FDTD（Lumerical） |
| 天线电大尺寸 | MoM / PO |
