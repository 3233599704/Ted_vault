# 边界条件设置

> 仿真结果对不对，80% 取决于边界条件设得对不对。

## 📖 是什么

边界条件是 PDE 求解在计算域边界上的约束。没有边界条件，方程有无穷多解。设错了边界条件，解得漂亮但答非所问。

## 🧠 电磁仿真中常见的边界条件

| 边界条件 | 缩写 | 物理含义 | 什么时候用 |
|:---|:---|:---|:---|
| 完美电导体 | PEC | E 切向 = 0 | 金属表面（理想化） |
| 完美磁导体 | PMC | H 切向 = 0 | 对称面（特殊） |
| 阻抗边界 | IBC | 模拟有限导电率 | 真实金属（铜/铝） |
| 吸收边界 | ABC | 模拟波"跑出去不回来" | 开放域（天线） |
| 完美匹配层 | PML | 更高精度的吸收边界 | 高精度辐射/散射问题 |
| 周期性边界 | PBC | 模拟无限周期结构 | 阵列天线、超表面 |
| 散射边界 | SBC | 平面波入射 + 出射 | 雷达散射截面 RCS |
| 波端口 | Wave Port | 传输线模式的激励/接收 | 波导/微带线 |
| 集总端口 | Lumped Port | 集中参数的激励 | 低频/集总元件馈电 |
| 对称边界 | Symmetry | 利用几何对称性减半计算 | 对称结构 |

## 🔧 选错边界条件的后果

| 设成 | 问题 |
|:---|:---|
| PEC 当 ABC 用 | 波打到边界全部反射回来，S 参数完全不对 |
| ABC 当 PML 用 | 高精度需求时吸收不干净，有虚假反射 |
| 没设端口 | 求解器不知道能量从哪进来 |
| 周期性忘了设 | 得到的是单个单元结果，不是阵列结果 |

## ⚠️ 常见坑

- **开放域问题漏了吸收边界**：天线、散射问题如果不设 ABC/PML，等于把天线放在一个金属盒子里
- **PML 层数不够**：PML 需要 5-15 层，太少吸收不干净
- **端口模式数设错**：多模波导只算了基模
- **周期性边界的相位差忘改**：扫描角不是零的时候必须手动设置
