# COMSOL Multiphysics

> 多物理场耦合的"瑞士军刀"——电磁、热、结构、流体、声学全在一个平台里。

## 🎯 COMSOL 的定位

- **核心优势**：多物理场耦合（其他软件要手动传数据，COMSOL 原生耦合）
- **核心方法**：有限元法（FEM）
- **适用场景**：学术研究、概念验证、中小规模耦合仿真

## 📐 模块体系

| 模块 | 做什么 | 典型接口 |
|:---|:---|:---|
| AC/DC Module | 静电场、静磁场、低频电磁 | 电流/电压/磁场 |
| RF Module | 高频电磁、天线、微波 | S 参数/模式分析 |
| Wave Optics Module | 光仿真、波导、光子器件 | 电磁波-频域/时域显式 |
| Heat Transfer Module | 热传导/对流/辐射 | 温度/热流 |
| CFD Module | 计算流体力学 | 速度/压力 |
| Structural Mechanics | 应力/应变/振动 | 位移/力 |
| LiveLink for MATLAB | COMOL ↔ MATLAB 交互 | 脚本化工作流 |

## 🛠️ 通用工作流

1. **选择空间维度**：3D / 2D 轴对称 / 2D / 1D
2. **选择物理场**：添加所需模块的物理场接口
3. **几何建模**：CAD 导入或内置几何工具
4. **定义材料**：从材料库加载或手动设置
5. **设置物理边界条件**：最关键的步骤
6. **网格剖分**：物理场控制网格 / 用户控制网格
7. **研究步骤**：稳态 / 频域 / 瞬态 / 参数扫描
8. **求解**
9. **后处理**：绘图组、派生值、报告

## ⚠️ COMSOL 常见坑

- **多物理场耦合的收敛问题**：耦合越强越难收敛，需要合理设置求解器序列
- **RF 模块的网格需求**：每波长至少 5 个二阶单元
- **参数化扫描的内存**：扫太多参数值会把内存撑爆
- **版本兼容性**：COMSOL 不同大版本之间文件不兼容
- **License 限制**：部分模块需要单独 License（如优化模块、CAD Import）

## 📝 推荐学习顺序

1. 从 AC/DC Module 入手 —— 物理最直观
2. 做一遍完整案例（几何 → 边界 → 网格 → 求解 → 后处理）
3. 加第二个物理场做耦合
4. 学参数化扫描和结果处理
5. 学 LiveLink for MATLAB 做自动化
