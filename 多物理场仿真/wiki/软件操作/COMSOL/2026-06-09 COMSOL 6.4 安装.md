# COMSOL 6.4 安装

> 2026-06-09，Windows 环境，COMSOL Multiphysics 6.4.0.293。

| 项目 | 内容 |
|:---|:---|
| 版本 | 6.4.0.293 |
| 许可证号 | 6464550 |
| 安装路径 | `D:\Staid\app\COMSOL\COMSOL64\Multiphysics\` |
| 占用空间 | ~24 GB |
| 系统 | Windows 10.0 amd64 |
| Java | OpenJDK 21.0.7 |

## 目录结构

```
D:\Staid\app\COMSOL\
└── COMSOL64\
    └── Multiphysics\
        ├── bin\           # 可执行文件
        ├── java\          # JRE
        ├── lib\           # 核心库
        ├── plugins\       # 插件
        ├── applications\  # 应用模块
        ├── doc\           # 文档 & Help
        ├── license\       # 许可证文件
        └── uninstall\     # 卸载程序
```

## 备注

- 安装日志：`comsolsetup.log`（安装根目录下，2105 行）
- 偏好设置：`comsol.prefs`
- 卸载：运行 `uninstall\` 下卸载程序即可
